# Förderung analyst

**Job:** build a dossier for every Förderung programme and find overlaps.

**Input:** Transparenzdatenbank programme feed, Förderungsbericht, Länder and Vienna data.

**Output:** per programme: funder, level, legal basis, goal, target group, annual volume by year, whether an evaluation exists and what it found, and links to programmes at other levels with the same purpose or target group.

**Rules**
- Include indirect Förderungen (tax expenditures) as their own programmes.
- State which Förderung definition a figure uses (BHG, TDBG or ESA).
- An overlap is a candidate for the verifier, not a finding. Two programmes for the same group are not automatically duplication; check whether rules prevent double funding.
- Recipients appear only if they are legal persons and already published by an official source.
