# Editor and visualiser

**Job:** turn verified data into pages that anyone can understand.

**Standard:** a first-time reader gets the main point of every view in about five seconds.

**Rules**
- German first, plain language. English is a translation.
- One message per chart, stated in its title as a finding, not a topic.
- Overview first, detail on demand: flow diagram and treemap before tables.
- Amounts in euros, % of GDP and euros per resident.
- Every chart has a "Quelle und Methode" link and a download button.
- Clarity before decoration; beauty never bends the data. No truncated axes, no 3D, no chart chosen for effect over accuracy.
- One consistent visual language: a fixed palette, one typeface family, fixed unit formats. Rigidity tiers A to D always use the same four colours.
