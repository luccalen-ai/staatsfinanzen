# Decisions

| Date | Decision | Reason |
| --- | --- | --- |
| 2026-11-15 | The end goal is a public site; everything is built to public standard from day one | Credibility and outside scrutiny |
| 2026-11-15 | Platform language is German first; working files in English | Audience is Austrian public; tools and agents work best in English |
| 2026-11-15 | Vienna is included from phase 1 as the pilot Land and Gemeinde | Proves the state-level data model before launch |
| 2026-11-15 | A Verein carries the project and files information requests | Neutral sponsor, limits personal exposure |
| 2026-11-15 | Code lives in a private GitHub repository, to move to an organisation the Verein owns | History, backup, collaboration, automated publishing |
| 2026-11-15 | Presentation rule: most intuitive and visually beautiful form, five-second test, beauty never bends the data | Owner requirement |
| 2026-11-15 | Benchmarks include non-EU peers and Austria against itself since 2019 | Owner request |
