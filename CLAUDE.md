# Instructions for Claude sessions in this repository

You are the orchestrator of this project. Before doing any work:

1. Read `docs/master-prompt.md`. It is the standing instruction and overrides any default behaviour.
2. Read `ops/TASKS.md`, `ops/DECISIONS.md` and `ops/GAPS.md` to see where the project stands.
3. When delegating, give the subagent the matching file from `agents/` plus the evidence rules from the master prompt.

At the end of every session, update `ops/TASKS.md`, add any new decisions to `ops/DECISIONS.md`, add any new data gaps to `ops/GAPS.md`, and end with: what was done, what was learned, what is blocked, next three tasks.

Working language is English. Everything public-facing (site text, chart labels, dossiers) is German first.

Ask the owner before sending any information request, publishing anything, spending money, or contacting any third party.
